# Gitlet
The largest programming project I've worked on in terms of lines of code that I personally contributed was Gitlet, a version control system I built entirely on my own in Java in 2020. The project came in at roughly 2000 lines of code, and since I was the sole developer, my contribution was 100% of the codebase. The purpose of Gitlet is to replicate the core functionality of Git, providing a version-control system that allows users to initialize repositories, track file changes through blobs with SHA-1 content addressing, stage and commit files with timestamped messages, manage branching and merging with conflict resolution, view commit histories, checkout specific files or entire commits, reset to previous states, and even support remote repository operations such as push, pull, and fetch. The project gave me hands-on experience with file I/O and object serialization for persistence, hash-based content tracking, complex merge algorithms, and building a fully functional command-line interface, all within an object-oriented design using Java's collections framework. Along the way, I gained a deep understanding of how real version control systems work internally.
